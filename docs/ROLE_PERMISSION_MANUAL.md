## 権限設定の概要

TimeBaseでは、各ユーザーに**ロール（役割）**を割り当てることで、アクセスできる機能や操作できるデータの範囲を制御します。

ロールは以下の2つの要素で構成されます：
- **機能権限**: 各カテゴリ（ユーザー管理、シフト管理など）に対する操作権限
- **ページアクセス権限**: 各画面へのアクセス可否

---

## 対象範囲の説明

対象範囲は、どのユーザーのデータにアクセスできるかを決定します。

| 対象範囲 | 説明 | 例 |
|----------|------|-----|
| **自分のみ** | 自分自身のデータのみ閲覧・編集可能 | 一般スタッフが自分のシフトだけを見る |
| **担当者** | 自分が管理者として割り当てられているユーザーのデータ | チームリーダーが部下のデータを管理 |
| **会社内** | 同じパートナー会社に所属するユーザー全員のデータ | 派遣会社の管理者が自社スタッフを管理 |
| **全員** | システム内の全ユーザーのデータにアクセス可能 | システム管理者が全データを管理 |

### 対象範囲の階層

```
全員 > 会社内 > 担当者 > 自分のみ
```

上位の範囲は下位の範囲を含みます。例えば「会社内」を選択すると、「担当者」と「自分のみ」のデータにもアクセスできます。

---

## 権限レベルの説明

権限レベルは、対象データに対してどのような操作ができるかを決定します。

| 権限レベル | 説明 | 具体的な操作例 |
|-----------|------|---------------|
| **なし** | アクセス不可。該当機能は表示されません | - |
| **閲覧** | データの表示のみ可能。変更はできません | 一覧表示、詳細確認、検索 |
| **編集** | データの追加・変更が可能 | 新規登録、既存データの編集 |
| **管理** | 全ての操作が可能。削除・承認・ロック解除などの管理操作を含む | 削除、承認/却下、ロック/解除、強制操作 |

### 権限レベルの階層

```
管理 > 編集 > 閲覧 > なし
```

上位の権限は下位の権限を含みます。「管理」権限があれば、「編集」と「閲覧」の操作も可能です。

## 権限カテゴリ詳細

### 1. ユーザー管理

スタッフのアカウント管理に関する権限です。

| 権限レベル | 可能な操作 |
|-----------|----------|
| なし | ユーザー情報にアクセス不可 |
| 閲覧 | ユーザー一覧・詳細の表示 |
| 編集 | ユーザーの新規登録、プロフィール情報の編集 |
| 管理 | ユーザーの削除、ロール変更、アカウント有効/無効化 |

**関連するページアクセス**: ユーザー管理画面

---

### 2. シフト管理

シフトの登録・管理に関する権限です。

| 権限レベル | 可能な操作 |
|-----------|----------|
| なし | シフト情報にアクセス不可 |
| 閲覧 | シフト一覧・カレンダーの表示、自分のシフト確認 |
| 編集 | シフトの登録・編集、シフト申請の提出 |
| 管理 | シフト申請の承認/却下、シフト登録のロック/解除、強制登録 |

**関連するページアクセス**: シフト申請、出勤者管理、シフト一覧、シフト登録、登録ロック管理

---

### 3. 勤怠管理

出退勤記録の管理に関する権限です。

| 権限レベル | 可能な操作 |
|-----------|----------|
| なし | 勤怠情報にアクセス不可 |
| 閲覧 | 勤怠記録の表示、履歴確認 |
| 編集 | 勤怠記録の修正（自分 or 対象範囲のユーザー） |
| 管理 | 代理打刻、勤怠データの削除、レポート出力 |

**関連するページアクセス**: 打刻、勤怠履歴、レポート

---

### 4. 経費管理

経費精算・定期代の管理に関する権限です。

| 権限レベル | 可能な操作 |
|-----------|----------|
| なし | 経費情報にアクセス不可 |
| 閲覧 | 経費一覧・詳細の表示 |
| 編集 | 経費の登録・編集、定期代の申請 |
| 管理 | 経費の承認/却下、経費登録のロック/解除、締切無視での登録、経費削除 |

**関連するページアクセス**: 経費精算、経費月別一覧、経費ロック管理

---

### 5. システム設定

システム全体の設定管理に関する権限です。

| 権限レベル | 可能な操作 |
|-----------|----------|
| なし | システム設定にアクセス不可 |
| 閲覧 | 設定情報の表示（読み取りのみ） |
| 管理 | 会社情報の編集、ロールの作成・編集・削除、パートナー会社の管理 |

> **注意**: システム設定には「編集」レベルはありません。「閲覧」または「管理」のいずれかを選択してください。

**関連するページアクセス**: システム管理、パートナー管理

## ページアクセス権限

各ページへのアクセス可否を個別に設定できます。

### 基本機能

| ページ | 説明 |
|--------|------|
| ダッシュボード | メインホーム画面。本日の予定や通知を表示 |
| 打刻 | 出勤・退勤の打刻画面 |
| 勤怠履歴 | 個人の勤怠履歴確認画面 |

### シフト管理

| ページ | 説明 |
|--------|------|
| シフト申請 | 個人のシフト希望を提出する画面 |
| 出勤者管理 | 本日の出勤者一覧を確認する画面 |
| シフト一覧 | 全体のシフト状況をカレンダー形式で確認 |
| シフト登録 | シフトの登録・編集を行う管理画面 |
| 登録ロック管理 | シフト登録期間のロック/解除を行う画面 |

### 経費管理

| ページ | 説明 |
|--------|------|
| 経費精算 | 経費の登録・申請画面 |
| 経費月別一覧 | 月別の経費一覧表示 |
| 経費ロック管理 | 経費登録のロック/解除管理 |

### レポート

| ページ | 説明 |
|--------|------|
| レポート | 勤怠・経費のレポート出力画面 |
| 一括編集 | 複数ユーザーのデータを一括編集 |

### 管理機能

| ページ | 説明 |
|--------|------|
| ユーザー管理 | スタッフの登録・編集・削除 |
| パートナー管理 | パートナー会社の登録・管理 |
| システム管理 | 会社設定、ロール管理 |

## 推奨ロール設定例

### 一般スタッフ（STAFF）

最小限の権限を持つ一般ユーザー向けロール。

| カテゴリ | 対象範囲 | 権限レベル |
|---------|---------|-----------|
| ユーザー管理 | 自分のみ | なし |
| シフト管理 | 自分のみ | 閲覧 |
| 勤怠管理 | 自分のみ | 閲覧 |
| 経費管理 | 自分のみ | 編集 |
| システム設定 | - | なし |

**ページアクセス**: ダッシュボード、打刻、勤怠履歴、シフト申請、経費精算

---

### チームリーダー（LEADER）

担当チームの管理権限を持つリーダー向けロール。

| カテゴリ | 対象範囲 | 権限レベル |
|---------|---------|-----------|
| ユーザー管理 | 担当者 | 閲覧 |
| シフト管理 | 担当者 | 編集 |
| 勤怠管理 | 担当者 | 編集 |
| 経費管理 | 担当者 | 閲覧 |
| システム設定 | - | なし |

**ページアクセス**: 基本機能 + シフト一覧、シフト登録

---

### パートナー会社管理者（PARTNER_ADMIN）

自社スタッフの管理権限を持つパートナー会社の管理者向けロール。

| カテゴリ | 対象範囲 | 権限レベル |
|---------|---------|-----------|
| ユーザー管理 | 会社内 | 編集 |
| シフト管理 | 会社内 | 管理 |
| 勤怠管理 | 会社内 | 管理 |
| 経費管理 | 会社内 | 管理 |
| システム設定 | - | なし |

**ページアクセス**: 基本機能 + シフト全般、経費全般、レポート

---

### システム管理者（SUPER_ADMIN）

全ての権限を持つ最上位の管理者ロール。

| カテゴリ | 対象範囲 | 権限レベル |
|---------|---------|-----------|
| ユーザー管理 | 全員 | 管理 |
| シフト管理 | 全員 | 管理 |
| 勤怠管理 | 全員 | 管理 |
| 経費管理 | 全員 | 管理 |
| システム設定 | - | 管理 |

**ページアクセス**: 全ページ

## トラブルシューティング

### 権限エラーが表示される場合

1. **ページにアクセスできない**: ページアクセス権限が無効になっている可能性があります
2. **データが表示されない**: 対象範囲が狭すぎる可能性があります
3. **編集ボタンが表示されない**: 権限レベルが「閲覧」になっている可能性があります
4. **削除・承認ができない**: 権限レベルを「管理」に変更してください

### 権限変更後の反映

権限を変更した場合、対象ユーザーは**再ログイン**が必要です。ログアウト→ログインで新しい権限が反映されます。
